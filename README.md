# Minesweeper game

[![miner.airat.top](https://raw.githubusercontent.com/AiratTop/miner.airat.top/main/public_html/canvas.png)](https://miner.airat.top/)

A small browser-based version of the classic Minesweeper game, featuring a modern UI, dark mode, and multiple difficulty levels. Deployed as static assets on Cloudflare Workers.

- Live site: https://miner.airat.top
- Status page: https://status.airat.top

[![miner.airat.top](https://raw.githubusercontent.com/AiratTop/miner.airat.top/main/public_html/screenshot.png)](https://miner.airat.top/)

## Deployment

Cloudflare Workers Builds deploys the contents of `public_html` as static assets. The project has no build step; deployment uses `npx wrangler deploy` with the settings in `wrangler.jsonc`.
